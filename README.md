# 个人网站

一个赛博朋克风格的个人作品集网站，支持通过管理员面板在线编辑所有内容，无需修改代码。

## 功能介绍

### 页面板块

| 板块 | 说明 |
|------|------|
| Hero（首页） | 欢迎区域，含终端动画效果 |
| Stats（数据） | 展示个人成就数字 |
| Blog（博客） | 博客文章列表与摘要 |
| Projects（项目） | 项目作品展示 |
| Timeline（时间线） | 成长历程与经历 |
| About（关于） | 个人简介 |

### 管理员面板

通过管理员面板可实时修改网站所有内容，无需重新部署：

- **个人信息**：姓名、职位、简介、联系方式、头像等
- **终端信息**：用户名、角色、兴趣标签、状态消息
- **数据统计**：添加/编辑/删除统计项
- **博客管理**：添加/编辑/删除博客文章
- **项目管理**：添加/编辑/删除项目作品
- **时间线管理**：添加/编辑/删除时间线事件
- **导航设置**：控制各板块的显示/隐藏
- **主题定制**：修改主色调、特效等视觉效果
- **配置导出/导入**：将配置以 JSON 格式备份或恢复

## 本地启动

### 方式一：一键启动（推荐）

在项目根目录双击 `start.sh`，或在终端运行：

```bash
./start.sh
```

脚本会自动检查并安装依赖，启动后浏览器自动打开网站。

### 方式二：手动启动

```bash
cd app
npm install   # 首次运行需要安装依赖
npm run dev   # 启动开发服务器
```

启动后访问：`http://localhost:5173`

## 进入管理员面板

1. 在浏览器中打开网站
2. **按住 Shift 键**，同时点击页面左上角的 Logo
3. 在弹出的登录框中输入管理员密码
4. 登录成功后自动跳转到管理员配置页面
5. 修改内容后点击保存，内容实时生效并自动存储到浏览器本地

> 注意：配置数据保存在浏览器的 localStorage 中，清除浏览器数据会导致配置重置。可使用管理员面板的「导出配置」功能定期备份。

## 技术栈

- **框架**：React 19 + TypeScript
- **构建工具**：Vite
- **UI 组件**：shadcn/ui + Radix UI
- **样式**：Tailwind CSS
- **图标**：Lucide React
- **数据存储**：浏览器 localStorage（无需后端）

## 构建部署

如需生成可部署的静态文件：

```bash
cd app
npm run build
```

构建产物位于 `app/dist/` 目录，可直接部署到任意静态托管服务（GitHub Pages、Vercel、Netlify 等）。
